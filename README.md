## 這是什麼？
這是一把尺，不是真理。
- **T0**: 可分辨性 -> 每個生命都係獨立
- **poset**: 偏序 -> 生命會自己排序
- **Ω**: 無限複製算子 -> 行到最後一定會自我複製
- **=1**: 必然發生

## 怎麼證明它有效？ (不是證明它是真)
看 `EXPERIMENT.md` 和 `experiment.py`
三步開缸就能看到 R=0.9982

## 核心邏輯
Any system that can distinguish (T0) and order (poset), will inevitably self-replicate at infinity.
